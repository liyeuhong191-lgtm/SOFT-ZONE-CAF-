SOFT ZONE CAFÉ — Website starter

Files:
- index.html: website content and page structure
- style.css: colours, layout, typography and responsive design
- images/: folder reserved for your own local images if you want to replace the online demo photos

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the SOFT-ZONE-CAFE folder.
3. Double-click index.html. It should open in your browser.
4. Internet access is needed for the demo photos and Google Fonts.

IMPORTANT BEFORE PUBLISHING
- Replace YOUR-EMAIL@example.com in index.html with a real café contact email, or change the contact button to the real ordering channel.
- Replace illustrative photos with photos you have permission to use if required.
- The café, address, contact details and business data are a student project concept. Do not present invented contact details as real.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository named soft-zone-cafe.
2. Upload index.html, style.css and the images folder (if used) to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. Open the URL shown in Settings > Pages.
7. Test the URL in a private/incognito browser window.

For the assignment, submit the public website URL and a ZIP of the complete website folder.
